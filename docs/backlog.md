# Backlog

1. Como cliente, quiero registrarme e iniciar sesión, para acceder a mi cuenta.
2. Como cliente, quiero solicitar una cita en un horario disponible, para reservar una sesión. Requiere: #1.
3. Como cliente, quiero consultar mis solicitudes y citas, para conocer su estado. Requiere: #2.
4. Como administrador, quiero consultar la agenda futura, para conocer las citas solicitadas y confirmadas. Requiere: #2.
5. Como administrador, quiero aceptar o rechazar solicitudes, para gestionar las citas pendientes. Requiere: #2.
6. Como administrador, quiero proponer otro horario, para ofrecer una alternativa al cliente. Requiere: #2.
7. Como cliente, quiero consultar una propuesta de horario y aceptarla o rechazarla, para resolver mi solicitud. Requiere: #6.
8. Como cliente, quiero cancelar una cita respetando el límite de 24 horas, para liberar un horario que no voy a utilizar. Requiere: #2.
9. Como administrador, quiero configurar la disponibilidad semanal habitual, para definir cuándo se pueden solicitar citas.
10. Como administrador, quiero bloquear horarios o días específicos, para impedir nuevas solicitudes en esos períodos.
11. Como administrador, quiero administrar el catálogo de servicios, para mantener actualizadas las opciones disponibles.
12. Como administrador, quiero bloquear o borrar un servicio, para controlar las opciones disponibles y mantener actualizado el catálogo.
13. Como administrador, quiero consultar los datos de los clientes y su historial de citas, para gestionar sus reservas.
14. Como cliente, quiero cerrar sesión, para salir de mi cuenta en el dispositivo que estoy usando. Requiere: #1.
15. Como administrador, quiero gestionar las citas futuras desde el historial de un cliente, para atender cambios y cancelaciones. Requiere: #6 y #13.
16. Como cliente, quiero recibir un email de bienvenida formal, divertido y con emojis al crear mi cuenta, para saber que mi registro se completó. Requiere: #1.
17. Como cliente y administrador, queremos recibir un email al solicitar una cita, para conocer su día, hora, servicio y estado pendiente; el administrador también recibe la identidad del cliente. Requiere: #2.
18. Como cliente, quiero recibir un email cuando el administrador acepte mi cita o proponga otro horario, para conocer la decisión y, ante una propuesta, el nuevo horario y cómo aceptarla o rechazarla desde la aplicación. Requiere: #5 y #6.
19. Como cliente, quiero recibir un email cuando el administrador cancele mi cita, para conocer la cancelación y su motivo. Requiere: #15.
